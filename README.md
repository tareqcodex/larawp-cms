# LaraWP CMS

LaraWP CMS is a Laravel-based content management system inspired by WordPress.

## Goal

Build a developer-friendly CMS on top of Laravel with familiar publishing workflows:

- Page and post management
- Categories and tags
- Theme support
- Plugin-like module support
- Media library
- Admin dashboard

## MVP Scope

The first milestone focuses on:

1. Laravel app foundation
2. Authentication and admin area
3. CRUD for posts and pages
4. Taxonomy support (categories/tags)
5. Basic theme layout system

## Status

This repository is currently in the planning/bootstrap stage.
